
# Airbnb Data Analysis
## Overview
A data analysis project using Airbnb listing data to understand **pricing, availability, room types, locations, and listing performance**.

## Key Analysis

* Average Price & Price Distribution
* Room Type Analysis
* Neighbourhood/Location Analysis
* Availability Analysis
* Reviews & Listing Performance

## Tools

**Python | Pandas | NumPy | Matplotlib | Seaborn | Data Cleaning | EDA | Data Visualization**

## Project Outcome

Identified patterns and trends in Airbnb listings to understand factors affecting **pricing, availability, and listing performance**.
